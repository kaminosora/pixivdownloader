# Pixiv 原图下载器 v1.2.0

首次公开发布。纯 Chrome Manifest V3 扩展，本地运行，无需辅助程序或外部转换服务。

## 功能

- 下载当前作品，或当前 Chrome 窗口内已打开的全部 Pixiv 作品；多图作品自动保存全部原图，推荐链接与其他窗口不加入。
- 下载前选择保存文件夹，随后直接批量写入，不逐张弹出另存为。
- 静态图片保留原始字节、格式与文件名；同名自动加序号，不覆盖已有文件。
- 动图转换为 GIF；超过 GIF 大小、帧数、像素量或时序限制时自动转 MP4，不支持 H.264 时转 WebM。
- 视频保留 Pixiv 每帧原始停留时间，包括最后一帧；不强制改成固定帧率。不保存 ZIP 或散帧。
- 支持取消、重试、网页内嵌面板和后台队列。

## 安装

1. 下载本 Release 附件 **pixiv-original-downloader-1.2.0.zip** 并解压。
2. 打开 `chrome://extensions`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择解压后的 **extension** 文件夹。
4. 在 Pixiv 登录并打开作品，在扩展面板选择保存文件夹。下载期间请保留文件夹设置页。

更新旧版时替换原加载目录中的文件，点击「重新加载」，再刷新 Pixiv 标签页。

`pixiv-original-downloader-1.2.0-source.zip` 与 GitHub 的 Source code 附件用于开发，需先执行 `npm ci`、`npm run build`；日常使用请选择上面的插件安装包。SHA-256 校验值见 **SHA256SUMS.txt**。

## 验证与范围

2026-11-14 发布前复验：83 项单元测试、14 项扩展浏览器流程、9 项真实视频编码/解码检查通过。H.264、VP9、VP8 均验证了不等帧间隔和末帧时长。

原生外部目录授权及真实 Pixiv 登录环境未完成自动端到端验收；目录写入自动测试使用真实 OPFS 句柄。完整证据及限制见仓库 `docs/verification.md`。

视频输出上限 256 MiB、最长边 1920；GIF 最长边 1280。动图输出为转换副本，静态图片保留原图。详情见 README。
